# 试管婴儿移植前除了补充叶酸还需要补充哪些营养?

> 更新时间：2026-09-15 (UTC+8)

试管婴儿移植前的营养补充需兼顾卵子 / 精子质量、内膜环境及胚胎着床需求，除叶酸外，以下营养素也至关重要，建议结合饮食或遵医嘱合理补充：

　　**一、维生素类**

　　**1. 维生素 D**

　　**作用**：调节免疫功能，改善子宫内膜容受性(内膜对胚胎的接受能力)，研究显示维生素 D 缺乏可能降低移植成功率。

　　**来源**：

　　食物：深海鱼(如三文鱼、鳕鱼)、蛋黄、强化乳制品。

　　日晒：每天 10~15 分钟日晒(手臂、面部暴露)促进自身合成(需注意避免暴晒)。

　　**补充建议**：检测 25 - 羟基维生素 D 水平，若缺乏(<20ng/ml)，可遵医嘱补充 400~2000IU / 天。

　　**2. 维生素 E（生育酚）**

　　**作用**：抗氧化，改善卵巢血流，保护卵子免受自由基损伤，同时可能增加子宫内膜厚度。

　　**来源**：

　　食物：坚果(如杏仁、核桃)、种子(向日葵籽)、植物油(橄榄油、玉米油)、菠菜。

　　**补充建议**：一般通过饮食获取即可，若需额外补充，建议不超过 400IU / 天(过量可能影响凝血功能)。

　　**3. 维生素 B6/B12**

　　**作用**：

　　B6：调节激素平衡(如孕酮合成)，缓解经前焦虑，改善黄体功能。

　　B12：参与 DNA 合成，预防贫血(尤其对素食者重要)，影响胚胎神经管发育。

　　**来源**：

　　B6：香蕉、牛油果、鸡胸肉、鹰嘴豆。

　　B12：动物肝脏、鱼类、乳制品，素食者需通过强化食品或甲钴胺补充剂获取。

　　**补充建议**：B6 每日推荐量 1.3~1.7mg，B12 为 2.4μg，可通过饮食满足，缺乏者(如巨幼细胞贫血)需遵医嘱补充。

　　**二、矿物质类**

　　**1. 铁**

　　**作用**：预防缺铁性贫血，保障卵子质量和胎盘发育(贫血可能导致着床失败或早期流产)。

　　**来源**：

　　血红素铁(易吸收)：红肉(牛肉、羊肉)、动物血、肝脏。

　　非血红素铁(需搭配维生素 C)：菠菜、黑豆、黑木耳。

　　**补充建议**：孕前血清铁蛋白<30μg/L 时需补铁，可选择硫酸亚铁(60~100mg 元素铁 / 天)，同时服用维生素 C 促进吸收。

　　**2. 锌**

　　**作用**：参与生殖细胞成熟，改善精子活力(对男方同样重要)，调节子宫内膜免疫细胞功能。

　　**来源**：牡蛎(含量很高)、瘦肉、豆类、坚果(如南瓜子)。

　　**补充建议**：女性每日推荐量 8mg，男性 11mg，过量可能抑制铜吸收，建议优先食补。

　　**3. 碘**

　　**作用**：甲状腺激素合成必需元素，甲状腺功能异常(如甲减)会显著降低试管婴儿成功率。

　　**来源**：海带(需适量，避免过量)、紫菜、加碘盐、海鱼。

　　**补充建议**：每日推荐量 150μg，备孕女性可选择含碘复合维生素(如爱乐维)，避免高碘饮食(如大量海带)影响甲状腺功能。

　　**三、脂肪酸类**

　　**1. Ω-3 脂肪酸（DHA/EPA）**

　　**作用**：

　　改善卵子线粒体功能，提高胚胎质量;

　　抗炎、调节子宫内膜血流，降低胚胎着床期炎症反应。

　　**来源**：深海脂肪鱼(如三文鱼、沙丁鱼)、亚麻籽、核桃、藻类补充剂(适合素食者)。

　　**补充建议**：每日摄入 200~300mg DHA，可通过每周 2~3 次深海鱼或藻油胶囊补充。

　　**2. 辅酶 Q10**

　　**作用**：增强卵巢线粒体能量代谢，改善高龄女性卵子质量(尤其适用于 AMH<1.0ng/ml 或卵泡少的患者)。

　　**来源**：牛肉、动物心脏、坚果(需高温烹饪破坏氧化酶)。

　　**补充建议**：一般需口服补充(200~600mg / 天)，至少提前 1~3 个月服用，可能提升卵子受精率和囊胚形成率。

　　**四、其他关键营养素**

　　**1. 肌醇（Myo-Inositol）**

　　**作用**：改善胰岛素抵抗(如多囊卵巢综合征患者)，调节卵泡发育，降低流产风险。

　　**来源**：全麦面包、豆类、坚果、水果(如橙子)。

　　**补充建议**：多囊患者可遵医嘱补充 2~4g / 天(搭配叶酸效果更佳)，非胰岛素抵抗者无需额外补充。

　　**2. 益生菌**

　　**作用**：调节肠道菌群平衡，促进营养吸收，改善全身炎症状态(慢性炎症可能影响内膜容受性)。

　　**来源**：酸奶(含活性菌)、泡菜、纳豆、益生菌补充剂(如含乳杆菌、双歧杆菌的制剂)。

　　**补充建议**：选择活菌数≥10^6 CFU / 克的产品，每日 1 剂，可长期服用。

　　**3. 蛋白质**

　　**作用**：构成卵子和胚胎的基础物质，维持内膜细胞修复，建议选择优质蛋白(如鱼、蛋、奶、豆类)。

　　**摄入量**：每日每公斤体重 1.2~1.5g(如 60kg 女性需 72~90g / 天)，可多吃鸡蛋、鸡胸肉、豆腐等。

　　**五、饮食原则与注意事项**

　　**均衡饮食为主，补剂为辅**：优先通过多样化饮食获取营养(如彩虹饮食法：每天摄入 5 种颜色的蔬果)，避免单一营养素过量。

　　**避免致畸或影响激素的食物**：

　　高汞鱼类(如鲨鱼、旗鱼);

　　过量咖啡因(>200mg / 天，约 2 杯美式咖啡);

　　加工食品(含反式脂肪、添加剂)。

　　**个体化调整**：

　　肥胖患者：控制总热量，避免高糖高脂饮食(可能降低卵子质量);

　　甲状腺疾病患者：根据甲功结果调整碘摄入(如甲亢需低碘饮食);

　　过敏体质：避免海鲜、坚果等易过敏食物，以防移植后免疫反应。

　　移植前 3~6 个月开始调整饮食结构，重点补充**抗氧化营养素（维生素 D、E、Ω-3）、造血元素（铁、B12）、生殖相关矿物质（锌、碘）**，同时结合自身基础疾病(如多囊、甲减)和营养检测结果(如维生素 D、铁蛋白水平)制定方案。建议在生殖科医生或营养师指导下，通过饮食 + 补剂实现精准营养支持，为胚胎着床和早期发育奠定基础。
